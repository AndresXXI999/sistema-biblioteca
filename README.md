# Sistema de Biblioteca

Proyecto de la clase de Diseño Web. Sistema para administrar el catálogo
de libros, los socios y los préstamos de la biblioteca del campus.

## Cómo correr la app
1. Tener JDK 17 y MySQL 8.0 instalados.
2. Copiar `application-local.properties.example` a
   `application-local.properties` y poner la contraseña de MySQL.
3. Ejecutar `./mvnw spring-boot:run` (Linux) o `mvnw.cmd spring-boot:run`
   (Windows).
4. Abrir http://localhost:8080 en el navegador.
